- `어린이사고_요일별_시간대별_2020_2024.xlsx`: weekday_time, 2020~2024, 시트 `YainSoft_Excel1`, 28행 x 68열
- `어린이사고_요일별_시간대별_2025.xlsx`: weekday_time, 2025, 시트 `YainSoft_Excel1`, 28행 x 15열

- `연도`: 집계 연도
- `요일`: 일, 월, 화, 수, 목, 금, 토
- `요일 정렬값`: 일요일 1부터 토요일 7까지의 정렬용 값

- `시작시각`, `종료시각`: 시간대 경계의 24시간 정수
- `사고건수`: 사고 발생 건수
- `사망자수`: 사망자 수
- `부상자수`: 부상자 수

### `taas_accident_type_time_2020_2025.csv`

- `연도`: 집계 연도
- `사고유형 대분류`, `사고유형 중분류`, `세부유형`: 원본 사고유형 계층
- `집계수준`: `중분류상세`, `세부상세`, `대분류단일` 등 원본 행의 집계 수준
- `시간대`, `시작시각`, `종료시각`: 2시간 단위 시간대와 경계
- `사고건수`, `사망자수`, `부상자수`: 원본 수치. 사고건수와 사상자수는 서로 다른 단위다.

총계와 소계는 `taas_weekday_time_totals_2020_2025.csv`, `taas_accident_type_time_totals_2020_2025.csv`에 별도 저장했다. 분석 시 총계, 대분류소계, 중분류소계를 상세 행과 함께 합산하면 중복 집계된다.

## 전처리 과정

1. `data_raw`의 엑셀 4개를 내부 헤더 기준으로 요일별·시간대별 2020~2024, 요일별·시간대별 2025, 사고유형별·시간대별 2020~2024, 사고유형별·시간대별 2025로 분류했다.
2. 병합 셀 때문에 비어 있는 연도, 요일, 사고유형 계층 값을 직전 유효 값으로 보정했다.
3. 2020~2024 파일의 전체기간 합계 열과 각 연도의 합계 열은 검증용 totals CSV에 분리했다.
4. 시간대 상세 열만 분석용 CSV에 펼쳤다.
5. 사고유형 계층은 원본에 없는 유형을 만들지 않고, 2025년에 없는 `도로이탈 기타` 같은 항목을 0으로 채우지 않았다.

- 사고유형 중분류 또는 세부유형별 시간대 분포

## 자료의 한계

- 전국 집계 통계라 지역별 위험도를 직접 설명하지 못한다.
- 지역명, 학교명, 좌표가 없어 지도 기반 위험지역 분석에는 사용할 수 없다.
- 어린이 전체 교통사고 통계이며 보행 어린이 사고만을 의미하지 않는다.
- 사고건수와 사망자수·부상자수는 단위가 다르므로 같은 의미로 비교하거나 합산하지 않는다.
- 2025년 사고유형 계층 일부가 2020~2024년과 다르므로 유형별 장기 비교 때 원본 계층 차이를 함께 표시해야 한다.

## 차트용 집계 CSV

`data_processed/taas/charts/`에 서비스 시각화용 집계를 저장했다. 모든 비율은 0~1 값이다.

- `taas_chart_yearly_totals.csv`: 연도별 사고건수, 사망자수, 부상자수. 분모 없음.
- `taas_chart_year_weekday.csv`: 연도별 요일별 사고건수와 `연도내_사고건수비율`. 분모는 같은 연도의 전체 사고건수다.
- `taas_chart_year_time.csv`: 연도별 시간대별 사고건수와 `연도내_사고건수비율`. 분모는 같은 연도의 전체 사고건수다.
- `taas_chart_year_weekday_time.csv`: 연도별 요일 x 시간대 사고건수. 비율은 사용 화면의 필요에 따라 위 두 집계의 분모를 선택하도록 별도 계산하지 않았다.
- `taas_chart_year_accident_type_major.csv`: 연도별 사고유형 대분류별 사고건수와 `연도내_사고건수비율`. 분모는 같은 연도의 전체 사고건수다. 원본의 대분류소계와 대분류단일 행만 사용한다.
- `taas_chart_year_car_person_middle.csv`: 연도별 차대사람 사고의 중분류별 사고건수와 `연도별_차대사람내_사고건수비율`. 분모는 같은 연도의 차대사람 사고건수다.
- `taas_chart_aggregation_validation.csv`: 차트용 집계가 전처리 검증 총계와 일치하는지 확인한 결과다.

총계, 소계, 세부 항목을 함께 합산하지 않았다. 사고유형의 연도별 계층 차이는 원본에 없는 항목을 만들지 않는 기존 원칙을 유지했다.
